# Szablony reklam — skrót nawigacji (NOW)

Ten moduł zbiera gotowe szablony pod reklamy (układ + wytyczne do generacji grafiki). Agent **NOW** dobiera je po intencji użytkownika.

## Gdzie są pliki

Wszystkie szablony leżą w `src/skills/marketing/templates/` i są widoczne w UI pod **Szablony reklam → szablony** (alfabetycznie po nazwie pliku `.md`).

## Jak dobierać szablon

- Dopasuj **format** (1:1, 4:5, 9:16) i **intencję** (UGC, dowód społeczny, porównanie, scroll-stop bez produktu itd.).
- Jeśli użytkownik nie wie: zadaj jedno pytanie o **kanał** (Meta / TikTok / X) i **etap lejka** (świadomość vs konwersja).

## Start (najczęściej)

- Editorial organiczny → `advertorial-editorial.md`
- TikTok przed/po → `tiktok-before-after.md`
- Scroll-stop bez produktu → `curiosity-gap-scroll-stopper.md`
- Komentarz + produkt → `social-comment-screenshot.md` lub `product-comment-callout.md`

Pełna lista jest w drzewku **szablony** — nie duplikuj jej tutaj ręcznie.
