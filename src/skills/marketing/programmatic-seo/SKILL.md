# Programmatic SEO (pSEO)

Budujesz **wiele stron pod szablony i dane**, które rankują, dają wartość użytkownikowi i unikają „thin content”.

## Zanim zaczniesz

Wczytaj kontekst produktu (`.agents/product-marketing-context.md`).

Ustal: produkt, audience, cel konwersji stron, wzorce zapytań, skala (ile URL), konkurencja, autorytet domeny, stack.

## Zasady

1. **Unikalna wartość na URL** — nie tylko podmiana `[miasto]` w tym samym bloku tekstu.
2. **Dane:** im bardziej **własne / trudne do skopiowania**, tym lepiej (własne &gt; z produktu &gt; UGC &gt; licencja &gt; public).
3. **URL:** preferuj **subfolder** (`/templates/resume/`) zamiast subdomeny dla konsolidacji autorytetu (ogólna zasada SEO).
4. **Intencja:** strona musi realnie odpowiadać zapytaniu.
5. **Jakość &gt; ilość** — set świetnych URL lepszy niż tysiące cienkich.
6. Unikaj: doorway pages, keyword stuffing, duplikatów bez wartości.

## 12 playbooków (skrót)

| Playbook | Wzorzec | Przykład |
|----------|---------|----------|
| Szablony | `[typ] template` | CV template |
| Kuracja | `best [kategoria]` | best website builders |
| Konwersje | `[X] to [Y]` | USD → PLN |
| Porównania | `X vs Y` | Webflow vs WordPress |
| Przykłady | `[typ] examples` | landing examples |
| Lokalnie | `[usługa] w [miasto]` | … |
| Persony | `[produkt] dla [audience]` | CRM dla nieruchomości |
| Integracje | `A + B integration` | Slack + Asana |
| Glosariusz | `what is [term]` | … |
| Tłumaczenia | wersje językowe | lokalizacja |
| Katalog | `[kategoria] tools` | AI copywriting tools |
| Profile | encje | … |

**Wybór:** integracje → masz integracje; templates/examples → produkt kreatywny; lokalnie → fizyczna obecność; comparisons → konkurencja; glossary → ekspertyza.

## Implementacja

1. **Research wzorca** — zmienne, liczba kombinacji, sumaryczny volume, head vs long tail.
2. **Dane** — źródło, świeżość, aktualizacja.
3. **Szablon strony** — H1, unikalny wstęp (nie tylko merge fields), sekcje data-driven, linkowanie wewnętrzne, CTA pod intencję.
4. **Linkowanie** — hub & spoke, brak sierot, breadcrumbs + schema gdzie ma sens.
5. **Indeksacja** — priorytet dla wolumenu; `noindex` dla bardzo cienkich wariantów; sitemapy per typ.

## Jakość (checklist)

Treść: unikalna wartość, odpowiedź na intencję, czytelność. Techniczne: unikalne title/meta, nagłówki, schema, wydajność. Linki: powiązane strony, sitemap.

**Po starcie:** indeks, pozycje, ruch, engagement, konwersje; reaguj na spadki i ostrzeżenia o jakości.

## Typowe błędy

Thin swap miast, kanibalizacja jednego keyworda, generacja bez popytu, złe dane, UX tylko pod bota.

## Output

analiza szansy, plan wdrożenia, wytyczne treści, szablon URL/title/meta, outline sekcji, schema.
