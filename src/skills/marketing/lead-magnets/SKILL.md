# Lead magnety

Projektujesz lead magnety, które zbierają maile, kwalifikują i naturalnie prowadzą do produktu.

## Zanim zaczniesz

Wczytaj kontekst produktu (`.agents/product-marketing-context.md`).

Zbierz: model biznesowy, ICP, obecny sposób zbierania leadów, assety do repurposu, cel (ilość vs jakość), etap lejka, timeline.

## Zasady

1. **Konkretny problem** — jeden ból, nie „wielki przewodnik po wszystkim”
2. **Dopasowanie do etapu** — awareness = edukacja; consideration = ewaluacja; decision = implementacja
3. **Wysoka postrzegana wartość, niski czas** — „wygląda jak płatne”, konsumpcja &lt;30 min (idealnie &lt;10)
4. **Naturalna ścieżka do produktu** — ten sam problem, który produkt rozwiązuje
5. **Łatwa konsumpcja** — jeden format, mobile-friendly, bez egzotycznego softu

## Typy (skrót)

| Typ | Wysiłek | Kiedy |
|-----|---------|--------|
| Checklist | niski | szybkie wygrane |
| Cheat sheet | niski | referencja |
| Szablon (doc/Notion/sheet) | średni | powtarzalny proces |
| Swipe file | średni | inspiracja |
| Ebook / guide | wysoki | autorytet |
| Mini-kurs mailowy | średni | edukacja + nurture |
| Quiz / assessment | średni | segmentacja |
| Webinar | średni | autorytet na żywo |

## Dopasowanie do etapu

**Awareness:** checklisty, cheat sheety, lekkie ebooki, quiz „kim jesteś”.

**Consideration:** arkusze porównań, assessment dojrzałości, case studies, webinar „jak wybrać”.

**Decision:** szablony wdrożeniowe, migration checklist, trial, kalkulator ROI (→ `free-tool-strategy`).

## Gating

| Podejście | Kiedy |
|-----------|--------|
| Pełny gate | wysoka wartość, dół lejka |
| Częściowy | podgląd + pełna wersja |
| Bez gate + opcjonalnie | TOFU edukacja |
| Content upgrade | bonus do konkretnego artykułu |

**Zasada:** minimum pól — każde dodatkowe obniża konwersję ~5–10%.

## Landing + delivery

Struktura: headline (korzyść), podgląd, „co w środku”, social proof, krótki formularz, FAQ.

**Thank you page:** potwierdzenie, następny krok (demo/trial), share, powiązana treść.

## Dystrybucja

- CTA w treściach + dedykowane upgrade’y pod wpis
- exit-intent / scroll (ostrożnie z irytacją)
- social: fragmenty, karuzele, CTA w bio
- paid: zgodnie z intencją (Google na szablony, Meta lead ads na TOFU)
- współpromocje z partnerami

## Metryki

Konwersja LP, CPL, lead→customer, engagement maili, czas do konwersji. Benchmarki mocno zależą od kanału — traktuj jako orientacyjne.

## Output strategii

1. Rekomendacja formatu + tematu + etapu  
2. Outline treści  
3. Plan gate + pola + struktura LP  
4. Plan dystrybucji  
5. KPI i pierwsze testy A/B
