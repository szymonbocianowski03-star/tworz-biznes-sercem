# Psychologia marketingu i modele mentalne

Stosujesz psychologię i modele myślenia **etycznie** — lepsze decyzje, lepszy copy, lepsze produkty marketingowe.

## Zanim zaczniesz

Wczytaj kontekst produktu (`.agents/product-marketing-context.md`).

Dla użytkownika: nazwij zachowanie do wpłynięcia, wiarę sprzed kontaktu, etap lejka, blokery działania.

## Część A — myślenie strategiczne

| Model | Idea | Zastosowanie |
|-------|------|--------------|
| First principles | buduj od prawd podstawowych, nie kopiuj ślepo | „Po co ten kanał?” zanim zrobisz tak jak konkurencja |
| Jobs to be Done | ludzie „zatrudniają” produkt do pracy | komunikuj outcome, nie listę feature’ów |
| Circle of competence | rób to, co umiesz | koncentracja kanałów tam, gdzie masz przewagę |
| Inwersja | co gwarantuje porażkę? | checklist „czego unikać” przed kampanią |
| Brzytwa Ockhama | najprostsze wyjaśnienie często trafne | najpierw oczywiste przyczyny spadku CR |
| Pareto | ~80% efektów z ~20% działań | tnij niskowartościowe działania |
| Lokalne vs globalne optimum | optymalizujesz zły element | najpierw kanał/strategia, potem mikro-optymalizacja |
| Theory of constraints | jeden wąskie gardło | traffic vs konwersja — napraw wąskie gardło |
| Koszt alternatywny | każdy wybór to rezygnacja z innego | porównuj z najlepszą alternatywą |
| Malejące korzyści skali | kolejne złote daje mniej | wiedz kiedy dywersyfikować |
| Myślenie drugiego rzędu | skutek skutku | promocja może nauczyć czekania na rabat |
| Mapa ≠ terytorium | model ≠ rzeczywistość | rozmawiaj z klientami, nie tylko z dashboardem |
| Myślenie probabilistyczne | scenariusze, nie „pewniak” | rozłóż ryzyko kampanii |
| Strategia barbell | 80% bezpiecznie + 20% eksperymenty | unikaj „średniego ryzyka bez payoffu” |

## Część B — jak kupują ludzie

| Efekt / bias | Mechanizm | Marketing |
|--------------|-----------|-----------|
| Błąd atrybucji podstawowej | winimy „charakter” zamiast kontekstu | napraw proces zanim obwinisz usera |
| Mere exposure | lubimy znajome | konsekwentna obecność marki |
| Heurystyka dostępności | co łatwo przychodzi do głowy wydaje się częstsze | case’y i historie „blisko” |
| Confirmation bias | szukamy potwierdzenia | zakotwicz w istniejących przekonaniach lub zmieniaj łagodnie |
| Lindy | co długo trwa, często dłużej przetrwa | nie porzucaj fundamentów dla mody |
| Mimetyczne pragnienie | chcemy tego co „ci fajni” | waitlista, social proof, ekskluzywność (autentyczna) |
| Koszt utopiony | trzymamy się złych inwestycji | tnij kampanie bez wyniku |
| Endowment | cenniej to co „nasze” | trial, darmowe próbki |
| IKEA effect | wartość rośnie z wysiłkiem | konfiguratory, „zbuduj swój plan” |
| Zero-price | „darmowe” to nie tylko niska cena | free tier / shipping jako dźwignia |
| Hyperbolic discounting | preferujemy teraz > później | korzyści natychmiastowe w copy |
| Status quo | zmiana jest kosztowna psychicznie | redukcja friction migracji |
| Default effect | akceptujemy domyślne | domyślny plan (etycznie) |
| Paradox of choice | za dużo opcji paraliżuje | 2–3 plany, jedna rekomendacja |
| Goal-gradient | przyspieszamy blisko mety | pasek postępu, „już prawie” |
| Peak-end rule | ocena przez szczyt i koniec | mocne zakończenie onboardingu / thank you |
| Zeigarnik | niedokończone ciągnie | lekkie „open loops” (bez manipulacji) |
| Pratfall | mała wada u kompetentnych buduje sympatię | uczciwa wada vs. korzyść |
| Klątwa wiedzy | ekspert nie wie jak to wygląda dla laika | testuj copy na świeżych głowach |
| Mental accounting | ramy „skrzynek” na pieniądze | „$1/dzień” vs miesięczna kwota |
| Awersja do żalu | boimy się żałować | gwarancje, trial, jasne „wyjście” |
| Social proof / bandwagon | idziemy za tłumem | liczby, logo, recenzje (prawdziwe) |

## Część C — perswazja (etycznie)

- **Reciprocity** — daj wartość przed prośbą (content, narzędzie).
- **Commitment & consistency** — małe kroki przed dużymi (email → trial).
- **Authority** — ekspertyza, certyfikaty, „featured in”.
- **Liking / similarity** — język „jak Ty”, founder story.
- **Unity** — wspólna tożsamość grupy.
- **Scarcity / urgency** — tylko jeśli **prawdziwe**.
- **Foot-in-the-door** — mała prośba → większa.
- **Door-in-the-face** — duża kotwica, potem realna oferta (ostrożnie z etyką).
- **Loss aversion** — straty bolą ~2× mocniej niż zyski cieszą → ramy „co tracisz”.
- **Anchoring** — pierwsza liczba ustawia percepcję (cena referencyjna).
- **Decoy** — trzeci gorszy plan podkreśla środkowy.
- **Framing** — to samo w dwóch ramach („90% sukcesu” vs „10% niepowodzeń”).
- **Contrast** — mocny „before” dla „after”.

## Część D — psychologia cen

- **Charm pricing (.99)** — wrażenie niższej ceny (B2C value).
- **Round prices** — płynność i „premium” ($500 vs $497).
- **Rule of 100** — poniżej $100 lepiej %, powyżej lepiej kwota absolutna.
- **Good-better-best** — środek jako cel strategiczny.
- **Relatywność cen** — opcje ułatwiają wybór.

## Część E — projektowanie doświadczeń

- **Hick’s law** — więcej opcji = wolniejsza decyzja.
- **AIDA** — uwaga → zainteresowanie → pragnienie → akcja.
- **Rule of 7** — wiele touchpointów przed konwersją.
- **Nudge / choice architecture** — domyślne, kolejność, tarcie.
- **BJ Fogg** — zachowanie = motywacja × zdolność × prompt (wszystkie 3).
- **EAST** — Easy, Attractive, Social, Timely.
- **COM-B** — capability, opportunity, motivation.
- **Activation energy** — pierwszy krok musi być trywialny.
- **North Star Metric** — jeden wskaźnik jako kompas.
- **Cobra effect** — złe incentywy mogą zepsuć system (testuj).

## Część F — skala i wzrost

- **Feedback loops** — wzmacniaj pętle „user → treść → SEO → user”.
- **Compounding** — małe stałe ruchy > rzadkie skoki.
- **Network effects** — wartość rośnie z liczbą userów (projektuj produkt).
- **Flywheel** — każdy element napędza następny.
- **Switching costs** — retencja przez integracje i dane (etycznie).
- **Exploration vs exploitation** — balans eksperymentów z optymalizacją.
- **Critical mass** — najpierw głęboko w jednym segmencie.
- **Survivorship bias** — ucz się też z porażek ukrytych.
