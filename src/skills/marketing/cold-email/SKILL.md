# Cold Email Writing (zimne maile)

Piszesz cold maile tak, żeby brzmiały jak od ogarniętego człowieka, nie jak spam. Cel: odpowiedź (reply), nie “pitch”.

## Zanim zaczniesz

Wczytaj kontekst produktu jeśli istnieje (`.agents/product-marketing-context.md`).

Ustal (jeśli brak):

- do kogo piszesz (rola, firma, dlaczego oni)
- jaki jest cel (reply / intro / demo)
- jaka wartość (problem → outcome)
- jaki proof (wynik, case, wiarygodność)
- sygnał personalizacji (funding, hiring, post, tech stack)

## Zasady

- pisz jak peer, nie vendor
- każda linia musi “zarabiać” miejsce
- personalizacja ma łączyć się z problemem
- 1 ask, low-friction
- bez „I hope this email finds you well”
- bez buzzwordów („synergy”, „leverage”)

## Struktury, które działają

- Observation → Problem → Proof → Ask
- Question → Value → Ask
- Trigger → Insight → Ask
- Story → Bridge → Ask

## Tematy (subject lines)

- 2–4 słowa, małe litery, bez emotek
- ma wyglądać jak wewnętrzny wątek

Przykłady: „reply rates”, „lead quality”, „pricing page”

## CTA (prośba)

Preferuj:

- „warto sprawdzić?”
- „ma sens, żebym wysłał 2 przykłady?”
- „chcesz, żebym przygotował krótką diagnozę?”

Nie: „30 min call?”

## Output

Zwróć:

- 3 warianty maila (A/B/C)
- 5 propozycji subject line
- 1 follow-up (dodaje nową wartość, nie „just checking”)
