# Sales enablement (B2B)

Tworzysz materiały, których **reprezentanci faktycznie używają** — decki, one-pagery, objection library, scenariusze demo, playbooks.

## Zanim zaczniesz

Wczytaj kontekst produktu (`.agents/product-marketing-context.md`).

Zbierz: propozycja wartości, differentiators, motion (inside/field/PLG-assisted), ACV, cykl, persony w decyzji, istniejące assety, co repy proszą najczęściej.

## Zasady

- **Współtwórz z najlepszymi repami** — ich język, nie tylko marketingowy.
- **Konkretna sytuacja** — persona × etap × use case; unikaj „uniwersalnego” ścianomatu.
- **Skanowalność w 3 sekundy** — nagłówki, krótkie punkty, hierarchia.
- **Każda obietnica → „co z tego dla biznesu”** — czas, przychód, ryzyko, koszt.

## Pitch deck (10–12 slajdów, szkielet)

1. Problem w świecie klienta  
2. Koszt braku działania  
3. Zmiana rynku / presja  
4. Wasze podejście (inaczej niż alternatywy)  
5. Produkt — **3–4 workflow**, nie katalog feature’ów  
6. Dowody (metryki, logo, analitycy)  
7. Jeden case  
8. Wdrożenie / timeline  
9. ROI / wartość  
10. Cennik (orientacyjnie)  
11. Next steps  

**Zasady:** jeden pomysł na slajd; slajd wspiera rozmowę, nie zastępuje; historia, nie feature tour.

**Dostosowanie:** techniczny buyer (architektura, security, API) vs ekonomiczny (ROI, TCO, ryzyko) vs champion (wewnętrzna sprzedaż, quick wins).

## One-pager

Jedna strona: problem → rozwiązanie → **3 differentiators** → jeden mocny proof → CTA z kontaktem konkretnej osoby.

## Obiekcje

Dla każdej: jak słyszane sformułowanie → **prawdziwy powód** → odpowiedź → dowód → pytanie follow-up.

Format krótki (do rozmowy) + opcjonalnie długi (trening).

## Demo script

Otwarcie (kontekst, agenda) → rekapitulacja discovery → **15–20 min** przejście po 3–4 workflow powiązanych z bólem → pytania w trakcie → podsumowanie i następny krok z datą.

**Demo po discovery** — bez zrozumienia bólu zgadujesz feature’y.

## Case (format pod sales)

Profil klienta → challenge → solution → **3 metryki before/after** → cytat → tagi (branża, use case, wielkość).

## Kalkulator ROI

Wejścia: czas, koszty narzędzi, wielkość zespołu, błędy/inefektywność.  
Wyjścia: oszczędność, payback, 3-letnia wartość.  
Implementacja: arkusz (szybko) vs mini web (skala).

## Playbook

Profil kupującego, kwalifikacja, pytania discovery, top obiekcje, pozycja vs konkurencja, flow demo, szablony maili.

**Właściciel + przegląd kwartalny** — inaczej playbook gnije.

## Propozycja (oferta)

Executive summary (1 str.) → rozwiązanie vs wymagania → plan wdrożenia → inwestycja → next steps. **5–7 stron** celowo; executive summary zawsze custom pod rozmowę.

## Output

Outline slajd po slajdzie z notatkami speakera, pełny copy one-pagera, tabela obiekcji, scenariusz demo z timingiem, spec kalkulatora lub playbook TOC.
